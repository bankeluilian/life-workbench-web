# 设计系统

## 色板

- 页面背景：`#fffaf4` / `#fffdf9`
- 卡片背景：`rgba(255,255,255,.90)`
- 主文字：`#402d27`
- 次文字：`#8d7e77`
- 边框：`#f0dfd1`
- 珊瑚橙：`#ff8069`
- 奶油橙：`#f6a84c`
- 鼠尾草绿：`#8db45d`
- 淡紫：`#8d78d8`
- 柔粉：`#ef8489`

## 字体与间距

- 中文字体：PingFang SC、Microsoft YaHei、Noto Sans SC 回退
- 页面标题：18–31px / 700–780
- 卡片标题：16–20px / 700
- 正文：11–13px / 1.6–1.8
- 页面左右间距：15px，窄屏 11px
- 模块间距：14px；卡片内间距 12–16px

## 圆角、阴影与控件

- 卡片圆角：21px；弹层：30px；按钮：22–23px
- 卡片阴影：`0 10px 28px rgba(105,72,48,.08)`
- 底部导航高度：82px + safe area
- 主要点击区域：不小于约 44px
- 进度环：CSS `conic-gradient`，由实时数据计算
- 图表：可访问 SVG 折线、真实节点与标签
- 插画：来自 `public/assets/clean/illustrations` 的透明 PNG，仅用于局部视觉，不替代功能组件

## 响应式

- 手机优先：375、390、414、430px 单列
- 桌面保持 430px 居中的移动工作台形态
- 固定底部导航，内容区保留安全 padding
- 三列项目看板在手机内使用压缩网格，不产生横向滚动
