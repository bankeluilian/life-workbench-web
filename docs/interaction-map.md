# 交互映射

| 可操作元素 | 行为 | 数据影响 / 跳转 | 确认 | Toast / 撤销 |
| --- | --- | --- | --- | --- |
| 底部首页、支线、洞察、我的 | 路由切换并高亮 | 对应一级路由 | 否 | 否 |
| 中央加号 / 快速记录卡 | 打开全局 Bottom Sheet | 选择记录分类 | 否 | 否 |
| 快速记录分类 | 切换真实表单 | 草稿变脏时提示 | 有未保存内容时 | 否 |
| 保存运动、睡眠、收支、想法 | 校验并写入记录仓库 | 首页、支线、洞察同步 | 否 | 成功 Toast |
| 编辑 / 删除历史记录 | 表单回填或删除 | 对应记录数组 | 删除确认 | Toast |
| 任务圆形勾选 | 完成 / 取消完成 | 项目、支线、首页进度同步 | 否 | 否 |
| 任务文字 | 编辑名称与预计时长 | 任务仓库 | 否 | 保存 Toast |
| 删除任务 | 删除任务 | 任务仓库 | 是 | 5 秒撤销 |
| 项目三列箭头 / 拖放 | 调整 today、week、later | 项目任务 bucket | 否 | 否 |
| 开始 / 继续专注 | 打开全局计时器 | 活动专注状态 | 已有计时时阻止 | Toast |
| 暂停 / 继续 / 结束专注 | 更新、保存会话 | 专注统计和任务实际时长 | 提前结束确认 | Toast |
| 日期按钮 | 打开日期弹窗 | selectedDate | 否 | Toast |
| 支线卡片 | 进入详情 | `/branches/[id]` | 否 | 否 |
| 支线状态下拉 | 重点、保持、放缓、归档 | Branch.status | 否 | 否 |
| 学习分类标签 | 切换英语、阅读、专业 | 当前页面分类状态 | 否 | 否 |
| 最近笔记 / 新建 | 跳转详情或创建 | notes | 否 | Toast |
| 图表节点 | 显示该日详情 | 无写入 | 否 | Toast |
| 下周优先项 | 直接编辑并持久化 | nextPriorities | 否 | 自动保存 |
| 用户名 / 阶段 / 头像 | 编辑、选择、上传 | user | 校验用户名 | Toast |
| 主题与首页布局控件 | 实时更新外观和首页模块 | theme、dashboard | 重置默认无需确认 | Toast |
| 导出 JSON | 下载带版本号的备份 | 无写入 | 否 | Toast |
| 导入 JSON | 校验后覆盖当前数据 | 全局 AppState | 是 | 成功或错误 Toast |
| 全部数据清零 | 恢复零值默认状态 | 清空 v3 本地状态 | 二次确认 | Toast |
| 保存每日 / 每周复盘 | 新增或更新复盘 | reviews | 否 | Toast |
