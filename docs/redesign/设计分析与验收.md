# 人生支线工作台：HTML 视觉还原与功能补齐

日期：2026-10-14。依据用户提供的六张手机界面参考图，以及 bankeluilian/life-workbench-web 的现有独立 HTML 版本。

## 对照分析

参考图使用奶油白底色、细暖色描边、浅淡水彩装饰，主色为珊瑚橘，学习、健康、事业分别采用浅紫、鼠尾草绿和暖黄。卡片的圆角、阴影都比较轻，正文清晰，主标题带手写感。原 HTML 的强阴影、偏浓背景、分离的概览和纵向快捷记录，让信息密度和参考图有明显差距。

| 参考页 | 原 HTML 差异 | 本次修改 |
| --- | --- | --- |
| 首页 | 圆环内没有图标和标签；支持任务是列表；趋势与快速记录纵向排列 | 圆环内置图标与标签，三张支持任务卡，并排趋势与记录卡，小兔和花草嵌入卡片 |
| 我的支线 | 缺少月度重点、真实进度和卡片内趋势；保持支线入口无响应 | 月度重点、三条重点支线、趋势与下一步行动，保持与暂缓支线均可进入相关操作 |
| 学习成长 | 独立 HTML 中不存在 | 目标进度、英语/阅读/专业分类、每日计划、学习曲线、笔记与词汇复习 |
| 项目计划 | 独立 HTML 中不存在 | 12 周阶段、三列任务板、时间安排、真实关键结果、专注入口 |
| 快速记录 | 简单表单，无睡眠质量和状态 | 两列时间卡、评分滑块、三种状态、备注计数、快捷入口与大保存按钮 |
| 本周洞察 | 简单单曲线和静态热力图 | 真实周统计、睡眠/学习双曲线、四行热力图、依据本地记录生成的提示和可编辑优先事项 |

桌面端保留 430px 居中的移动工作台；375、390、430px 保持首页和学习页的双列区域。浏览器使用自身的系统状态栏，不额外伪造 9:41、信号和电量。天气区域为生活氛围展示，不提供虚假的实时天气。

## 功能与数据

- 保留 `life-workbench-html-v1` 存储键，读取旧版运动、睡眠、任务、专注和记录字段。新数据结构为 version 2；可恢复旧版 version 1 备份。
- 任务按日期记录完成状态；首页、学习页、项目页和洞察统一读取同一状态。支持新增、编辑、删除、完成、撤销、拖放分组；手机也可通过编辑菜单调整分组。
- 四类记录均可保存；睡眠增加质量与状态。运动按当天记录累计，睡眠采用当天最后一次记录。补录历史日期不会覆盖今天的兼容字段。
- 专注按实际时间记录，支持暂停、继续、结束和刷新恢复。计时使用持久化的开始时间，不依赖后台每秒回调。未满一分钟的时间也保存，不虚增一分钟。
- 笔记支持新增、编辑、删除；词汇复习可标记与撤销掌握。用户文本经过 HTML 转义。
- 主题、首页布局、页内专注提醒、名字与人生阶段可保存。记录可查看与删除。
- JSON 导出、恢复预览与确认、确认清零均可用。所有数据保存在当前浏览器，跨文件/设备请通过备份迁移。
- 所有进度从真实零记录开始；不会把参考图中的 75%、82%、72% 等示例数字写成用户成绩。词汇目标按已完成的预设 80 词任务累计；分类复习的三组词只是预置学习材料。
- 学习建议由本地规则生成，不调用外部 AI 服务；提醒是打开页面时的专注提醒，未实现操作系统后台通知。

## 文件与运行

- `html-export/index.html`、`workbench.css`、`workbench.js` 与 `assets/`：开发和维护版，直接双击 index.html 可离线使用。
- `html-export/人生支线工作台.html`：完全独立单文件，内嵌图片、样式和脚本，可单独复制并双击。
- `node tests/build-standalone.mjs` 或 `npm run build:html`：重新生成单文件。
- `npm run test:html`：Chrome 中执行 HTML 功能与布局测试。默认使用项目安装的 Playwright；也可设置 `WORKBENCH_PLAYWRIGHT` 指向环境提供的 Playwright 模块。
- `WORKBENCH_HTML` 可以指定另一个 HTML 文件路径，验证单文件或拷贝到其他目录后的版本。

## 验收范围

浏览器自动化覆盖 11 组场景：六页与任务同步、四类记录和历史日期、专注恢复与精确计时、旧备份与恢复清零、三种手机宽度的六张页面、任务和笔记的完整增删改及拖放、主题布局提醒与键盘操作、跨天数据隔离、异常任务与损坏数据保留、异常备份规范与图片字段转义、任务编号不复用。

开发版与独立移动到输出目录后的单文件分别执行整套测试，合计 22/22 通过。375、390、430px 的六页布局均无横向溢出、缺图和脚本错误，截图保存在 `docs/redesign/screenshots/`，适合展示的完整六页预览保存在 `docs/redesign/previews/`。独立代码复核发现的跨天迁移、异常数据读取、图标字段注入及任务编号复用问题均已修复，并有失败后转为通过的回归测试。

本次修改范围为独立 HTML。React 网站与服务器端代码未修改。字体与原图手写字形、插画笔触仍存在差异，这次是可交互的近似还原，不声称逐像素一致。
